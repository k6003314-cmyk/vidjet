# Локальный виджет расписания

Проект Android-приложения для группы ИСП-25-1. Расписание включено в приложение и читается с телефона; сетевые разрешения и сервер не используются.

## Что входит

- Виджет показывает текущую пару (или ближайшую, если сейчас перерыв) и занятие после неё: время, аудиторию и преподавателя.
- В настройках доступны фиолетовая, синяя, зелёная и красная темы. Цвет сохраняется на телефоне и применяется ко всем установленным экземплярам виджета.
- Поддерживаются обычный и компактный размеры: удерживайте виджет на главном экране и измените его высоту, чтобы он перестроил содержимое.
- В приложении доступно расписание по дням.
- Чётная и нечётная недели определяются по календарной нумерации ISO. Сверка: 28 октября 2026 года — чётная неделя, что совпадает с примером ответа бота.
- Кружок «Промт-инженер» добавлен на четверг с 16:50 (группа 1); Unity — на пятницу с 16:50 (группа 1).
- Период расписания: 1 сентября — 27 декабря 2026 года.

## Сборка

Откройте папку проекта в Android Studio с установленным Android SDK и JDK 17 или новее, выполните Gradle Sync и соберите APK через меню Build. Для первой сборки потребуется доступ к Google Maven и Maven Central, чтобы Android Studio загрузила библиотеки. После установки приложение и виджет работают без интернета.

Данные расписания находятся в `app/src/main/assets/schedule.json`.

## Сборка через GitHub

В проект добавлен workflow `.github/workflows/build-apk.yml`. После загрузки проекта в репозиторий GitHub сборка запускается при отправке изменений в ветку `main`; её также можно запустить вручную во вкладке Actions. Готовый `app-debug.apk` появится в файлах результата завершённой сборки.
